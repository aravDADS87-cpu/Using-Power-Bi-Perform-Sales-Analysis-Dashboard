📊 Power BI Sales Dashboard
📌 Project Overview

Developed an interactive Sales Dashboard using Microsoft Power BI to analyze sales performance, track business growth, and generate meaningful business insights.

🔹 Project Steps
Data Collection: Imported sales data from Excel/CSV files.
Data Cleaning: Used Power Query Editor to remove duplicates, handle missing values, and transform data.
Data Modeling: Created relationships between tables for effective data analysis.
DAX Calculations: Created measures to calculate Total Sales, Total Profit, Total Quantity, and other KPIs.
Dashboard Development: Designed an interactive dashboard using KPI cards, bar charts, line charts, and pie charts.
Filters & Slicers: Added interactive filters to analyze sales based on different categories, regions, and time periods.
Data Analysis: Identified top-performing products, sales trends, and regional performance.
Insights Generation: Generated meaningful insights to support better business decisions.
🛠️ Tools & Technologies
Microsoft Power BI
Power Query
DAX
Data Visualization
Data Modeling
🎯 Project Objectives
Analyze overall sales performance.
Track revenue and profitability.
Identify top-selling products and categories.
Understand regional sales performance.
Support data-driven business decisions.
📈 Project Outcome

Successfully developed an interactive Power BI Sales Dashboard that provides clear insights into business performance and helps in making informed decisions.
